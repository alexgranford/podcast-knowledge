# Security

## Supported versions

| version | supported |
| --- | --- |
| 6.0.x | yes |
| older | no |

## Reporting a problem

- **Use GitHub's private reporting:** the repository's **Security** tab, then **Report a vulnerability**. Please do not open a public issue.
- **Leave out real data:** no phone numbers, chat ids, API keys, tokens or the contents of `users.json`, `.env` or the state folder.
- **Include:** the version, what you did, what happened and what you expected.
